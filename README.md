# Wormenpracticum

Python rewrite of the UvA Psychobiologie wormenpracticum.

### Requirements

- [uv](http://docs.astral.sh/uv/getting-started/installation/)
- [VSCode (recommended)](https://code.visualstudio.com/)

### Development

```ini
# Setup
uv sync

# Design
uv run pyside6-designer

# Run
uv run main.py

# Build (Windows)
.\misc\build.ps1
```
